# vector-soccer (빨대 축구)

중학교 1학년 과학 **'알짜힘'** 단원의 빨대 축구를 1:1 대전 게임으로 옮긴 교실용 서버.
같은 교내망에 붙은 학생들이 **QR로 접속**해 방을 만들거나 친구를 초대해 겨룬다.
교사 PC에서 **exe 한 개를 더블클릭**하면 끝. 학생은 **앱 설치 없이 브라우저**로 들어온다.

📖 **선생님용 사용법은 [사용 설명서(MANUAL.md)](MANUAL.md)** 를 보세요. 이 README 는 만드는 사람을 위한 설명입니다.

구조는 형제 프로젝트 [classroom-quiz](https://github.com/TeaveloperHQ/classroom-quiz)와 같다(LAN 바인딩 · QR · 액터 모델 허브 · 결과 파일 저장).

## 게임 방식

- 학생이 화면을 **끌면** 끈 방향으로 빨대가 바람을 분다. **끈 길이에 비례**하는 힘이 0.35초 동안 공에 작용한다.
- 한 번 불면 **3초** 쉬어야 한다(이름 옆 동그라미 — 본인 것만 보인다). 불 때마다 다시 3초.
- 쉬는 중에 불기를 시도하면 **헛방질**: 쿨타임 +1초(남은 쿨타임 최대 6초). 짧은 실수 터치는 봐준다.
- 두 학생이 동시에 불면 두 힘이 더해진다. 화면에 각자의 힘 화살표와 **알짜힘**(보라색)이 표시되고,
  크기가 같고 방향이 반대면 "알짜힘 0 — 힘의 평형!"이 뜬다.
- 공에는 마찰력(운동 반대 방향, 일정 크기)과 공기 저항이 작용해 저절로 멈춘다. 벽·골포스트에서 튕긴다.
- 규칙은 방장이 고른다: **경기 시간**(1·2·3·5분, 끝나면 골 많은 쪽 승리 — 동점이면 **바람을 덜 분 쪽** 승리,
  그것도 같으면 무승부(토너먼트는 골든골)) /
  **목표 골**(3·5·7골 먼저) — 둘 중 하나 이상.
- 각자 화면은 **내가 오른쪽(세로 화면이면 위쪽)으로 공격**하도록 돌려서 그린다.
  색은 두 화면에서 같다: 방장(side 0) **파랑**, 들어온 쪽(side 1) **빨강** — 골대·빨대·힘 화살표·점수 모두.
  골대 뒤에 그 골대를 지키는 학생 이름이 붙는다.
- **추가시간**: 골 세리머니·재접속 후 카운트다운에도 시계는 흐르고 그만큼 쌓여, 정규 시간이 끝나면 "추가시간 +N초"로
  이어서 한다(시계 옆에 미리 표시). 연결 끊김 대기와 첫 킥오프 전 카운트다운은 시계가 멈춘다.
- 킥오프 때는 **선축**만 먼저 불 수 있다(5초 안에 안 불면 풀림, 기다리는 쪽 시도는 벌칙 없음).
  첫 선축: 초대 받은 사람 / 방에 들어온 사람 / 대회는 무작위 / 한 판 더는 직전 경기 진 사람(비기면 번갈아). 골 뒤에는 골 먹은 사람.
- 연결이 끊기면 경기(시계 포함)를 멈추고 **돌아올 때까지 기다린다.** 새로고침은 물론 브라우저를 닫고 새로 들어와도
  같은 학번·이름이면 그 경기로 복귀한다. 기다리던 쪽은 "기다리지 않고 끝내기"로 **기록 없이** 취소할 수 있다.
  둘 다 끊긴 채 10분이 지나면 기록 없이 정리. 연결된 상태에서 "나가기"는 기권패.
- 경기가 끝나면 **한 판 더**(둘 다 누르면 진영을 바꿔 새 경기) 또는 로비로.

## 대회 (교사 주관)

교사 화면 **대회** 탭에서 이름·방식·규칙을 정하고 접속한 학생 중 참가자를 골라 만든다. 한 번에 하나.

- **리그전**: 교사가 **조 수**를 정하면 참가자를 무작위로 고르게(인원 차 최대 1명) 나눈다. 조 안에서 모두 한 번씩
  (원형 방식 라운드, 홀수면 라운드마다 한 명 쉼), 모든 조의 같은 라운드는 동시에 진행. 승 3·무 1, 동점이면 득실차 → 다득점, 순위는 조별.
- **토너먼트**: 무작위 대진, 2의 거듭제곱에 모자라면 1라운드 부전승. 시간이 끝났는데 동점이면 **골든골**.
- 교사가 **"○라운드 시작"** 을 누르면 그 라운드 대진이 학생 화면에서 자동으로 경기로 열린다
  (결과 화면에 있던 학생도 데려온다). 접속 안 했거나 다른 경기 중인 학생의 경기는 건너뛰고 알려준다.
- 대진마다 ⋯ 메뉴: 이 경기만 시작 · 승자 지정(결석 부전승 등) · 경기 취소 · 결과 되돌리기
  (토너먼트는 다음 라운드가 시작되면 되돌릴 수 없음).
- 학생 로비에 "결승 · 상대: ○○", "탈락", "현재 2위" 같은 안내가 뜬다. 대회 경기는 다시 하기 없음.
- **크게 보기**로 프로젝터에 순위표/대진표를 띄운다.
- 진행 상황은 `competitions/<id>.json` 에 저장 — 서버를 다시 켜도 이어서 한다. 경기 결과 CSV 에 대회 이름이 붙는다.

## 교사 화면 (`/host`, 교사 PC에서만 열림)

- **경기장** 탭: 접속 QR(크게 띄우기) · 접속/경기 중/대기 방 수 · 진행 중인 경기 미니 경기장(실시간) · 학생 상태.
- **대회** 탭: 리그전(조 편성)·토너먼트 만들기 · 라운드 진행 · 순위표/대진표(위 "대회" 참고).
- **결과** 탭: 날짜별 필터 · 학생별 요약(경기·승무패·득실점·바람 횟수, 제목 눌러 정렬) · 경기 기록(삭제 가능)
  · **엑셀(CSV) 내려받기**(학생 한 줄씩, 경기당 2줄).

결과는 exe 옆 `results/<날짜>/<시각>-<경기id>.json` 에 한 판씩 저장된다.

## 빌드 / 실행

```bash
./build.sh                          # dist/vector-soccer.exe (콘솔 창 = 실행 중 표시, 닫으면 종료)
./build.sh dist/vector-soccer.exe gui   # 콘솔 없이(-H windowsgui)
go test ./...                       # 물리·규칙·로비·결과 테스트
VS_NO_BROWSER=1 go run .            # 개발 실행(브라우저 자동 열기 끔)
```

리눅스에서 윈도우 exe로 그대로 크로스컴파일된다(`CGO_ENABLED=0`). 기본 포트는 **8090**
(classroom-quiz 8080 과 동시에 켜도 겹치지 않게), 사용 중이면 다음 포트로 넘어간다.

## 설계 메모

- **서버가 물리를 계산한다(단일 진실원천).** 60Hz로 시뮬레이션하고 30Hz로 상태를 보낸다.
  학생 화면은 받은 위치+속도로 사이를 예측해 부드럽게 그린다. 쿨타임·입력 길이 제한도 서버가 강제한다.
- 모든 상태 변경은 `Hub.run()` 단일 고루틴 안에서만 일어난다(락 없음). 한 반 15경기 동시 진행도 부담 없음.
- 경기장 좌표는 가로 100 × 세로 60(추상 단위), 공 질량 1 → 힘 = 가속도. 조정값은 `match.go` 상단 상수.
- 학생 식별: `sessionStorage` 토큰 — 새로고침해도 같은 학생으로 복귀(경기 중이면 경기로).
  학번·이름은 `localStorage` 에 남아 다음에 자동으로 채워진다. 대회 참가자는 `학번|이름` 으로 찾는다.
- 경기 상태는 학생마다 따로 보낸다 — 쿨타임은 본인 것만.
- `/host`, `/info`, 결과 API, 교사용 WebSocket 은 `localOnly`(loopback)로 막는다.

### WebSocket 프로토콜 (`/ws?name=..&sid=..&token=..`)

| 방향 | 메시지 |
|---|---|
| 학생 → 서버 | `create{rules}` `cancel` `join{code}` `invite{to,rules}` `inviteReply{from,accept}` `blow{dx,dy}` `rematch` `leave` |
| 서버 → 학생 | `hello` `lobby{players,rooms,invites,sent,myRoom}` `match{side,names,rules,field}` `s{ph,b,sc,f,cd,pl,tl,on,...}` `notice` `error` |
| 서버 → 교사 | `host{players,matches,rooms}` (10Hz) · `comp{comp,standings,current,champion,online,busy,roundNames}` (바뀔 때) |
| 교사 → 서버 | `compCreate{name,type,rules,keys}` `compStartRound` `compStartFixture{id}` `compDecide{id,winner}` `compReset{id}` `compClose` |

`blow` 의 `(dx,dy)` 는 경기장 좌표계 벡터(길이 ≤ 1 = 세기 비율).

## 아이콘

`branding/` — teaveloper 공용 규격(1024 캔버스 · 800 라운드 사각형 rx 184 · 공식 그라데이션 · 흰 죽방).
죽방이 빨대로 바람을 불어 축구공을 민다. 작은 크기(16·32·48px)는 공과 빨대만 남긴 `icon-small.svg`.

```bash
cd branding && python3 gen.py        # icon.svg / icon-small.svg 다시 만들기
R="-density 384 -background none"
magick $R icon.svg -resize 1024x1024 app-icon-1024.png   # 512·256 도 같은 방식
magick \( $R icon.svg -resize 256x256 \) \( $R icon.svg -resize 128x128 \) \( $R icon.svg -resize 64x64 \) \
       \( $R icon-small.svg -resize 48x48 \) \( $R icon-small.svg -resize 32x32 \) \( $R icon-small.svg -resize 16x16 \) app.ico
cd .. && rsrc -ico branding/app.ico -arch amd64 -o rsrc_windows_amd64.syso   # exe 아이콘(윈도우 빌드 시 자동 링크)
cp branding/icon-small.svg assets/favicon.svg && cp branding/icon.svg assets/icon.svg   # 파비콘 · 입장 화면 로고
```
